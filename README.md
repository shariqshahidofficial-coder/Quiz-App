## About

An **interactive quiz application** that tests your knowledge with multiple-choice questions. Features score tracking, instant answer feedback, progress indicators, and a clean modern interface.

Built with **vanilla HTML, CSS, and JavaScript** -- no frameworks needed.

---

## Features

| Feature | Description |
|---------|-------------|
| Multiple Questions | Quiz with several questions |
| Score Tracking | Tracks correct answers |
| Instant Feedback | Shows if answer is right or wrong |
| Progress Bar | Shows quiz progress |
| Results Screen | Final score display |
| Play Again | Restart the quiz |
| Responsive | Works on all devices |
| Clean UI | Modern card-based design |

---

## Tech Stack
